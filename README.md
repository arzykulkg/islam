# islam
Kitaplar, ses, yazılar ve zikirmatik. İçerik eklemek için:
- Kitap: PDF'i `kitaplar/` klasörüne koy, `data/books.json` içine `{"t":"Ad","a":"Yazar","cat":"Kategori","file":"kitaplar/dosya.pdf"}` ekle.
- Ses: dosyayı `ses/` klasörüne koy, `data/audio.json` içine `{"t":"Başlık","a":"Okuyan","cat":"Kategori","file":"ses/dosya.mp3"}` ekle.
- Yazı: `data/posts.json` içine `{"id":"kisa-ad","t":"Başlık","date":"2026-10-28","cat":"Kategori","body":"Metin"}` ekle.
